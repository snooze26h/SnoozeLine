## Downstream changes

SnoozeLine introduces its own name and runtime directory, the built-in `snooze26h` theme, corrected context and quota semantics, safer rendering and collection behavior, and local-only build and migration documentation. Exact changes are recorded in downstream commits and [CHANGELOG.md](CHANGELOG.md).

The original `upstream` remote is retained for provenance. Upstream changes must be reviewed and integrated deliberately; they are never treated as SnoozeLine-authored work.

## License evidence

At `v1.1.2`, the following upstream materials declare the SPDX identifier `MIT`:

- `Cargo.toml`
- npm metadata for `@cometix/ccline@1.1.2`
- `README.md` and `README.zh.md`

However, the upstream `v1.1.2` tree and its preserved history do not contain the `LICENSE` file referenced by those README files. GitHub therefore does not detect a repository license.

SnoozeLine records those facts without inventing a license text or copyright holder. The repository remains private and has no release while the exact upstream notice is unresolved. This document is provenance evidence, not a replacement license or legal advice.
